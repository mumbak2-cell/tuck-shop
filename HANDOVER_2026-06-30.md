## What just shipped (this session, commit pending)

The 1000-row Supabase cap fix. PostgREST's project-level `max_rows` defaults to 1000 and silently truncates any `.limit()` we ask for. Devine Bakes' 1380-SKU export was capping at 999. The remedy is `.range()` pagination, which the cap doesn't apply to.

I built a small helper `src/lib/fetch-all.ts` exporting `fetchAllPaged<T>(buildQueryFactory)` that loops `.range(from, from+999)` until a partial page returns. Default page size 1000, hard cap 200k as a safety stop. Wired into every place a large catalogue could be truncated: `src/app/(dashboard)/products/page.tsx` (list fetch, export, categories merge, `ManageCategoriesModal` refresh, post-change reload), `src/app/(dashboard)/stock/page.tsx`, `src/app/(dashboard)/pos/page.tsx`, `src/app/(dashboard)/dashboard/page.tsx` (`downloadStockReport`), `src/app/(dashboard)/stock-transfers/page.tsx`, `src/app/(dashboard)/receive-stock/page.tsx`, and `src/lib/offline-sync.ts` (the offline cache refresh — important; without this, offline POS would have missed every SKU past 1000). The export also re-fetches products inside `handleExport` rather than trusting page state, so clicking Export before background fetch settles still yields a complete CSV.

## Architectural facts worth remembering

Per-location stock lives in `product_stock` keyed by `(product_id, location_id)`. The trigger `sync_product_opening_stock` keeps `products.opening_stock = SUM(product_stock.quantity)`, so writing to `products.opening_stock` directly is pointless — the trigger overwrites it. CSV import now seeds `product_stock` at `currentLocationId`.

Offline parity is complete (sales, expenses, customers, customer payments, shifts) — Phase 9C. Offline navigation no longer hijacks the app to a "You're offline" screen: `hasEverHadOrg` localStorage flag in `src/lib/org-context.tsx` bypasses the layout fallback when the user has a known org, and `onAuthStateChange` ignores `TOKEN_REFRESHED` events. POS was rebuilt for high-SKU operators with a searchable layout and a vertical category sidebar Valeron-style — see `src/components/pos/product-grid.tsx` with `RENDER_CAP = 200`. Categories come from the `categories` table merged with distinct `products.category` values so CSV-imported categories appear even if not formally seeded; `ManageCategoriesModal` in the Products page lets operators add, rename (cascades to products), or remove. Currency is per-org via `formatMoney` with the SADC catalog in `src/lib/currencies.ts`. Billing simplified to Paystack ZAR for all SADC; webhooks live, Flutterwave is stubbed.
